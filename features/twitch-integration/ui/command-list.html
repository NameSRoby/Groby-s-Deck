Formatting help

Bold: **text**. Lists: * item. Links: [label](https://example.com). Twitch panel line breaks use two spaces before a new line. Output is editable; edits stay until you update it or change your selection.

Each command gets its own copyable Discord code block. Replies, descriptions and limits stay outside the box. Rich embed cards require a bot or webhook and cannot be created by pasting ordinary text. Standard messages allow 2,000 characters; Discord Nitro allows 4,000. Formatting and line breaks count toward the limit. Each output part shows its actual size.

Discord parts are copied individually. Add more parts or use Update output if a manual edit exceeds the limit. For Twitch, choose a panel size and paste each part into a separate panel description.
