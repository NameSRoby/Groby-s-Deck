# Drop-in mods

Drop a mod folder or `.grobydeckmod` archive here. Open **Mods** in the app to review its permissions and approve it before enabling it.

`twitch-clips` is an editable example, discovered through this same process. It receives no automatic approval or special runtime exception. It calls the Core clipping capability after you connect Twitch and grant clip access.

Your installed copies and approvals live privately under `runtime/mods`. Removing the example source folder does not silently uninstall an approved copy. Disable or uninstall that copy through Mods.
